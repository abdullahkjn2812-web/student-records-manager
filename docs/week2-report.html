Marks (collection: marks)

FieldTypeRules

obtainedMarksNumberRequired, finite, 0 to totalMarks
totalMarksNumberRequired, finite, greater than 0
createdAt / updatedAtDateMongoose timestamps

A compound unique index on (student, subject) prevents two results for the same student and subject.

4. Database relationships

Student → Marks: one-to-many.

Each marks document stores the student’s _id in Marks.student. MongoDB does not create a SQL-style foreign key. Mongoose uses an ObjectId plus ref: "Student" so later code can populate() the student. This relationship is needed because one student has several subject results, while each result belongs to exactly one student.

User is independent in Week 2. No extra relationships were added.

The Express server binds to 127.0.0.1. A missing or invalid MongoDB URI stops startup. .env is gitignored.

7. Database setup

  1. Copy server/.env.example to server/.env.
  2. Set MONGO_URI to a local MongoDB database (default student_records_manager).
  3. From server/ run npm install then npm start.
  4. Confirm GET /health returns status: "ok" and database: "connected".
